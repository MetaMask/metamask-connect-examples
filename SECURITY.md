# Security Policy

## Important Context

This repository contains **example and quickstart code** for integrating with MetaMask Connect. These projects are intended for learning and prototyping purposes and are **not designed for production use**. They may not follow all security best practices required for a production application handling real funds.

**Do not use this code as-is in production.** Always perform your own security review before deploying any wallet-connected application.

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, **please do not open a public issue.** Public disclosure of vulnerabilities can put users at risk.

Instead, report vulnerabilities through MetaMask's responsible disclosure process:

- **HackerOne:** <https://hackerone.com/metamask>

When reporting, please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Which quickstart project is affected (e.g., `quickstarts/evm/react`)
- Any relevant environment details (browser, OS, MetaMask version)

## Scope

While these are example projects, we still want to know about:

- Vulnerabilities in dependencies used by the quickstarts
- Code patterns that could mislead developers into writing insecure production code
- Exposed secrets or credentials (even example ones that look real)
- Cross-site scripting (XSS) or injection vulnerabilities in the example UIs

## Response

The MetaMask team will acknowledge your report and work with you to understand and address the issue. We appreciate your help in keeping the MetaMask ecosystem safe.
