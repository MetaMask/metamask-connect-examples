# MetaMask Connect EVM React Quickstart

This is the quickstart of the [MetaMask Connect](https://docs.metamask.io/metamask-connect/evm/quickstart/react) with React.

## Clone the repository

```bash
git clone https://github.com/MetaMask/metamask-connect-examples.git
cd metamask-connect-examples/quickstarts/evm/react
```

or using [degit](https://www.npmjs.com/package/degit)

```bash
npx degit MetaMask/metamask-connect-examples/quickstarts/evm/react mm-connect-evm-react-quickstart && cd mm-connect-evm-react-quickstart
```

## Install dependencies

```bash
npm install
# or
pnpm install
# or
yarn install
```

## Create a `.env` file

```bash
cp .env.example .env.local
```

## Add your Infura API key

```bash
VITE_INFURA_API_KEY=your-infura-api-key
```

## Run

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```
